# Für Melli ♥ — Geburtstags-Liebesbrief

Eine kleine HTML-Seite mit Briefumschlag zum Anklicken, fliegenden Herzen und einem Brief, den du selbst beschreiben kannst.

## 📝 Brieftext ändern

Öffne `index.html` in einem Editor (VS Code, Notepad++, sogar Notepad reicht) und suche nach:

```
✏️ HIER DEINEN BRIEFTEXT EINFÜGEN / ÄNDERN ✏️
```

Darunter steht der Text des Briefes. Ändere ihn so wie du willst. HTML-Basics: `<p>...</p>` ist ein Absatz, `<h2>...</h2>` die Überschrift.

Vergiss nicht, am Ende deinen eigenen Namen einzutragen!

## 🚀 Auf GitHub Pages hosten (3 Schritte)

1. **Neues Repo erstellen** auf GitHub, z.B. `melli-birthday` (kann auch privat sein, für Pages muss es aber öffentlich sein — oder du brauchst GitHub Pro).
2. **Dateien hochladen**: Auf der Repo-Seite "Add file" → "Upload files" → den ganzen Inhalt dieses Ordners (`index.html` + Ordner `images/`) reinziehen → "Commit changes".
3. **Pages aktivieren**: Settings → Pages (linke Sidebar) → bei "Source" `Deploy from a branch` wählen → Branch `main` / Folder `/ (root)` → Save.

Nach 1–2 Minuten ist die Seite unter `https://DEIN-USERNAME.github.io/melli-birthday/` erreichbar. Diesen Link kannst du ihr schicken. 💌

## 🖱️ Lokal testen

Einfach `index.html` doppelklicken — öffnet sich im Browser. Fertig.
